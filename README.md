## 📌 Overview  
A **full-stack tourism platform** that connects travelers with:  
- 🏛️ **Hidden archaeological/offbeat sites**  
- 🧭 **Verified local tour guides** (30% commission per booking)  
- 🗺️ **AI-powered trip planner** with hotels/restaurants  

**Goal**: Combat overtourism and make exploration affordable.  

---

## 🚀 Key Features  
| Feature          | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| **Interactive Map** | Explore unknown places with Leaflet.js                                      |
| **Guide Booking**  | Hire locals directly (reviews, pricing, availability)                      |
| **Trip Designer**  | Custom or AI-generated itineraries                                         |
| **Price Compare**  | Avoid tourist traps with cost breakdowns                                   |

---

## 🛠️ Tech Stack  
**Frontend**: React + Tailwind CSS + Leaflet (maps)  
**Backend**: Node.js + Express  
**Database**: MongoDB (NoSQL for flexible data)  
**APIs**: Google Places, Payment Gateways  

---

## 📊 Market Validation  
- **1.9M+** annual visitors to Palestine *(target region)*  
- **700K+** seek guides; competitors like TripAdvisor serve 463M users  
- **Unique Edge**: First platform focusing on *unknown places* + *trip scheduling*
